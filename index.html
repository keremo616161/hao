📖 Flash-Anleitung

  1. Segway-App öffnen → Scooter entkoppeln
  2. SHU installieren: utility-beta.cfw.sh
  3. VPN aktivieren (außerhalb DE)
  4. Per Bluetooth mit Scooter verbinden
  5. FLASH → Load from File → ZIP wählen
  6. Nach Flash: App → Max-Speed setzen

🔓 Unlock-Code

Wähle eine Tastenkombination aus bis zu 10 Tasten (Blinker links/rechts, Mode, Power). Der Code wird während der Fahrt eingegeben und aktiviert das Tuning-Profil. Zurück zum Standard: Code erneut eingeben.

⚠️ Warnhinweise

• VCU-Version muss ≤ 1.4.10 sein
• Vor Flash in der App entkoppeln
• Flash-Reihenfolge: Erst VCU, dann MCU
• Cross-Flash zwischen Modellen kann bricken
