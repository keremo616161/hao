Flash-Anleitung

Schritt-für-Schritt für SHU

Vorbereitung

1. Segway-App → Scooter entkoppeln
2. SHU v3/v4 installieren: utility-beta.cfw.sh
3. VPN aktivieren (außerhalb DE)
4. Mit Scooter per Bluetooth verbinden

Flashen

1. FLASH → Load from Repo → VCU → flashen
2. FLASH → Load from Repo → MCU → flashen
3. TOOLS → change region → US
4. Nach Flash: App → Max-Speed auf 40 km/h
