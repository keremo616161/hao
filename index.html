Flash-Anleitung

Schritt-für-Schritt für ScooterHacking Utility (SHU)

Vorbereitung

1. Segway-App öffnen → Scooter entkoppeln (unbind)
2. SHU (ScooterHacking Utility) v3/v4 installieren: utility-beta.cfw.sh
3. VPN aktivieren (Standort außerhalb Deutschlands) für Repo-Zugriff[reference:4]
4. Mit dem Scooter per Bluetooth verbinden

Flashen

1. FLASH → Load from Repo → VCU → letzte Version flashen[reference:5]
2. FLASH → Load from Repo → MCU → letzte Version flashen[reference:6]
3. TOOLS → change region → US wählen[reference:7]
4. Alternativ: Deine eigene ZIPv3-ZIP via Load from File flashen
5. Nach Flash: Segway-App öffnen → Max-Speed auf 40 km/h stellen

⚠️ Wichtig: VCU-Version muss ≤ 1.4.10 sein. Nach Firmware-Updates kann Tuning zurückgesetzt werden. Bei CRC-Fehler: Erst Stock-BLE flashen, dann MCU/VCU, dann BLE erneut.
