Flash-Anleitung

Schritt-für-Schritt für ScooterHacking Utility

Vorbereitung

1. Segway-App öffnen → Scooter entkoppeln
2. SHU v3/v4 installieren: utility-beta.cfw.sh
3. VPN aktivieren (Standort außerhalb Deutschlands)
4. Mit dem Scooter per Bluetooth verbinden

Flashen

1. FLASH → Load from Repo → VCU → flashen
2. FLASH → Load from Repo → MCU → flashen
3. TOOLS → change region → US
4. Nach Flash: App öffnen → Max-Speed auf 40 km/h

💡 Tipp: Der Panic Button erlaubt sofortigen Wechsel in den StVZO-Modus per Tastendruck. Power-Modus: Gas + Bremse gleichzeitig beim Einschalten.
